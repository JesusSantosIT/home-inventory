How to Connect

Each household runs its own instance. Connecting is a two-way key exchange:

  1. They share their key with you: on their instance they generate an Instance API Key (card above on their External Households page) and send it to you
  2. You add them: click "Add External Household", enter their name, base URL, and paste their instance API key in "Their Instance API Key"
  3. You share your key with them: send them your Instance API Key (or a per-household key) so they can add you the same way
  4. Now you can click the button on their row to see their items available for lending — and they can see yours

Without a valid API key, a household sees nothing — the key is the only thing that grants access to the lending API.

API Endpoints:

  • GET /users/api/v1/available-items/ - Browse available items
  • POST /users/api/v1/request-lending/ - Request to borrow items
  • GET /users/api/v1/items/<id>/ - Get item details
